# Buryatia Esports

Сайт местного киберспорта Республики Бурятия — новости, игроки, команды и турниры
(по образцу HLTV). Флаг Flask + SQLite, полностью готов к запуску.

## Что внутри

- **Главная** — новости, ближайшие турниры, топ игроков
- **Новости** — лента новостей с детальными страницами
- **Игроки** — рейтинг, статистика (Rating, K/D, карт сыграно, побед), фильтр по игре
- **Команды** — список, профиль команды, состав
- **Турниры** — список, регистрация команды на турнир, список заявок
- **Регистрация команды** — публичная форма, заявки уходят на модерацию
- **Админка** (`/admin`) — логин, дашборд, CRUD для новостей/игроков/команд/турниров,
  одобрение команд и заявок на турниры, загрузка фото через форму

## Запуск локально

```bash
pip install -r requirements.txt
python app.py
```

Сайт откроется на `http://localhost:5000`
Админка: `http://localhost:5000/admin/login`

**Логин по умолчанию:** `admin` / `buryatia2026`
⚠️ Обязательно смени пароль перед публикацией в интернет (через `Admin.set_password()`
в консоли Python или добавь страницу смены пароля).

## Первый запуск (если базы данных ещё нет)

Если файла `esports.db` нет — просто запусти `python app.py`, база создастся
автоматически и админ `admin/buryatia2026` появится сам.

Либо через Flask CLI:
```bash
flask --app app init-db
```

## Куда вставлять свои материалы (для вайбкодинга)

| Что хочешь добавить | Куда идти |
|---|---|
| Фото игрока + статистику | `/admin/players` → кнопка «+ Добавить игрока» → заполни форму, прикрепи фото |
| Логотип и данные команды | `/admin/teams` → «+ Добавить команду» (или одобри заявку с сайта) |
| Новость с картинкой | `/admin/news` → «+ Добавить новость» |
| Турнир с обложкой | `/admin/tournaments` → «+ Добавить турнир» |
| Своё лого сайта / название | `templates/base.html` — строка `<a class="logo">BURYATIA<span>ESPORTS</span></a>` |
| Цвета/стиль | `static/css/style.css` — переменные `:root` в начале файла (`--accent`, `--bg` и т.д.) |

**То есть весь контент (фото, статистику, новости) не нужно вставлять в код —
всё загружается через админку в браузере.** Код трогать нужно только если
хочешь поменять дизайн, добавить новую страницу или новую игру/раздел.

## Как задеплоить в интернет (чтобы был реальный сайт с адресом)

Проще всего — **Render.com** (бесплатный тариф):
1. Залей папку проекта на GitHub
2. На render.com → New → Web Service → подключи репозиторий
3. Build command: `pip install -r requirements.txt`
4. Start command: `gunicorn app:app`
5. Добавь `gunicorn` в requirements.txt перед деплоем:
   `pip install gunicorn` → допиши строку в requirements.txt

Также подходят: PythonAnywhere, Railway, Fly.io — процесс похожий.

⚠️ SQLite подходит для старта, но при росте нагрузки (много пользователей одновременно)
стоит перейти на PostgreSQL — Flask-SQLAlchemy это поддерживает, достаточно поменять
`SQLALCHEMY_DATABASE_URI` в `app.py`.
